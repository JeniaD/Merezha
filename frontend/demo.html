Fractal demo · Mandelbrot on the marketplace

The image is split into a grid. Each tile is one hash task: the poster commits to keccak256(utf8(base64(RGBA))); workers echo the same string from the payload (Merezha hash handler). Tiles appear as workers finalize on-chain. Main app

Setup

Setup

Batch mode: fewer signatures than one-tx-per-tile. With large tile payloads we send at most two tiles per postBatch (execution gas); otherwise simulation often reverts with no data. On-chain poster is the batch contract; your wallet is the beneficiary for cancel/refund there.

Larger grids or tiles mean larger calldata per task (base64 RGBA). Very large batches in one tx can exceed block gas limits — use sequential mode or a smaller grid. Connect wallet, then Post all tasks. Run workers with the same marketplace address.
